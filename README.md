# 🛒 Shop Closing System

A Python and Streamlit application developed to simplify the shop closing process by automating daily cash reconciliation and reducing manual calculations.

Built to meet a client's specific requirements, this system provides an intuitive interface for balancing tills, recording transactions, and verifying daily totals quickly and accurately.

## 🚀 Features

- 💷 Cash till balancing
- 💳 Card payment reconciliation
- 🧮 Automatic calculations and validation
- 📊 Clear and user-friendly Streamlit interface
- ⚡ Reduces manual errors and saves time during shop closing
- 🔒 Designed specifically around the client's workflow

## 🛠️ Built With

- 🐍 Python
- 🎈 Streamlit

## 🎯 Purpose

This project was created as a real-world solution for a retail business, demonstrating how Python and Streamlit can be used to automate everyday business processes, improve accuracy, and increase efficiency.
